# B2B Graphite & Petrol — старт разработки через Codex

**Что это:** зафиксированное R1-ТЗ на основании утверждённых решений №1–108 и инфраструктурный каркас R1-001. Актуальные команды запуска и проверок находятся в [README.md](README.md).

## Установка в новый репозиторий

1. Распаковать архив в корень пустого репозитория: `AGENTS.md` на верхнем уровне, остальные файлы в `docs/spec/`.
2. Прочитать `docs/spec/00_README.md`, затем `docs/spec/02_RELEASE_SCOPE.md` и `docs/spec/03_MASTER_TZ_R1.md`.
3. Открыть `docs/spec/INITIAL_CODEX_PROMPT.md` и передать текст первого задания ведущему агенту Codex.
4. Утвердить технические ADR первого PR, затем принять каркас R1-001 и двигаться по `09_ROADMAP_BACKLOG.md`.

**Ограничение:** склад, заказы и производство не входят в R1; исходные решения сохраняются для последующих релизов. Не запускать парсинг чужих сайтов без подтверждения разрешений и правил использования.
