## Неизменяемые границы

- Все FROZEN R1-002A/R1-004A contracts и решения №1–108.
- Существующая identity tuple, product revision/state machine, publish flow и audit transaction rules.
- Нет новых catalog permissions в R1-002/R1-004 artifacts; protected admin sets прежние.
- До per-row staff command нет товара/ревизии; принятие создаёт/готовит только DRAFT; publication остаётся отдельной командой R1-004B.
- Нет supplier import, quote-spec import, OCR/PDF, prices/stock, bulk acceptance, background schedules, new infrastructure, production migration/deployment.
