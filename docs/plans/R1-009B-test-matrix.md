## Baseline observations

R1-008B and R1-009A prose still carry Draft labels even though PRs #59 and #60 are merged and runtime routes/tests exist. This proposal uses the merged behavior. R1-009A DB requires baseRevisionId, its API always selects an existing offer, and the Staff UI accepts a specific offer UUID. Price freshness is derived in R1-007 and does not expose a public supplier price. Existing ingestion OpenAPI includes the merged R1-009A routes. The baseline documents and generated artifacts remain historical references.
