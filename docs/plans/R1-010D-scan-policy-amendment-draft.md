## CSV profile assignment

For the initial candidate, exactly one of the two versioned comma/semicolon profiles is active in trusted server policy at a time. The trusted service binds its exact policy version and profile ID to each newly claimed job before examining the file; evidence records that immutable assignment and DB compares it at finalize. No file content, filename, client parameter, automatic guessing, fallback or retry with another dialect may authorize CLEAN. A change of assignment or concurrent active profiles requires a separately specified trusted selection context and owner approval; already bound jobs are not silently reinterpreted. Both grammars are tested independently using separately configured isolated test policies.
