# R1-010 Inquiry Contract Acceptance Matrix — PROPOSED 0.1.0

| ID      | Scenario                                                                  | Required result                                                                                                                                         | Verification after approval                              |
| ------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| REQB-01 | Guest creates request without account                                     | NEW Inquiry, receipt and audit commit; no session or customer account                                                                                   | PostgreSQL + public HTTP                                 |
| REQB-02 | EQUIPMENT with multiple items                                             | Every raw line, SKU/manufacturer/modification, quantity string, unit and note is preserved; no float or auto-match                                      | HTTP + PostgreSQL                                        |
| REQB-03 | PANELS DEVELOP_FROM_BRIEF                                                 | Correct kind-specific required fields persist exactly; attachments remain separate                                                                      | HTTP + PostgreSQL                                        |
| REQB-04 | ENGINEERING request                                                       | Direction, system type, technical task and deliverables persist; no technical approval is inferred                                                      | HTTP + PostgreSQL                                        |
| REQB-05 | Same create command/key retried                                           | Exact stored 201 receipt replays; one Inquiry, lines and audit                                                                                          | PostgreSQL idempotency integration                       |
| REQB-06 | Same key with different canonical payload                                 | 409 IDEMPOTENCY_KEY_REUSED; no second Inquiry or success audit                                                                                          | HTTP + PostgreSQL                                        |
| REQB-07 | Public caller attempts to change status                                   | No public route exists; method/path returns safe non-enumerating denial and state stays unchanged                                                       | OpenAPI negative + black-box HTTP                        |
| REQB-08 | Wrong inquiry capability, UUID-only access, or another Inquiry's intent   | Unauthorized/non-enumerating error; no metadata or bytes disclosed                                                                                      | HTTP + storage assertions                                |
| REQB-09 | Reuse a consumed/cancelled/expired intent or attach it to another Inquiry | 409/404 safe result; at most one document per intent and Inquiry binding unchanged                                                                      | HTTP + PostgreSQL concurrency                            |
| REQB-10 | Invalid, MIME-mismatched or malicious-signature fixture                   | Invalid content rejected before attach; accepted unknown content remains QUARANTINED and is not downloadable; no fake CLEAN state                       | Security fixtures + HTTP + storage                       |
| REQB-11 | Two staff transitions race using same ETag                                | At most one succeeds; loser gets VERSION_CONFLICT; final state/version/history/audit agree                                                              | Real PostgreSQL concurrency with lock/final-row evidence |
| REQB-12 | Staff lacks read/action permission                                        | 403/default deny regardless of UI state or assigned URL UUID                                                                                            | HTTP RBAC matrix                                         |
| REQB-13 | Public DTO/logs vs internal comments/contact data                         | Public receipt never returns contact, status, staff IDs, comments, filenames, hashes, storage keys or capability; logs redact them                      | Schema contract + log capture                            |
| REQB-14 | Optional notification adapter throws after Inquiry commit                 | Created Inquiry remains committed and 201 remains authoritative; notification delivery is deferred to R1-017 and never runs inside create transaction   | Fault injection + PostgreSQL                             |
| REQB-15 | Upload fails after Inquiry creation                                       | Inquiry and previous docs remain; failed/partial file is unattached and eligible only for exact owned cleanup                                           | Storage fault injection + PostgreSQL                     |
| REQB-16 | Each accepted original is stored                                          | Immutable bytes, actual size, SHA-256, detected MIME, safe filename, channel and timestamp are reconstructable; no parser output in R1-010              | Storage + PostgreSQL                                     |
| REQB-17 | Repeat identical staff command after API restart                          | Exact sanitized receipt replay; one state update, comment, audit event; no body/PII retained in idempotency row                                         | PostgreSQL + process restart                             |
| REQB-18 | Concurrent same key and identical payload                                 | One command commits, all callers receive identical saved result                                                                                         | Real PostgreSQL concurrency                              |
| REQB-19 | Concurrent same key but different payload                                 | Winner commits once; other caller gets IDEMPOTENCY_KEY_REUSED and no partial writes                                                                     | Real PostgreSQL concurrency                              |
| REQB-20 | Redis unavailable or untrusted X-Forwarded-For provided                   | Public write fails closed or uses only configured direct/proxy peer; attacker header cannot evade throttling                                            | HTTP + controlled Redis outage                           |
| REQB-21 | Scanner absent or scan error                                              | Document stays QUARANTINED/SCAN_ERROR; download and R1-011 access denied                                                                                | Runtime + DB state                                       |
| REQB-22 | Exact clean document download                                             | Requires read scope + both document permissions + CLEAN state; streamed no-store attachment, no static URL                                              | HTTP + permission matrix                                 |
| REQB-23 | Upload MIME, size, file-count and request limits                          | Rejected at streaming boundary before final document row; partial bytes cleaned only by exact write ownership                                           | Boundary fixtures + storage assertions                   |
| REQB-24 | Expired intent/abandoned temporary bytes cleanup                          | Only task-owned expired records/objects are removed; no Inquiry, completed document, audit or unrelated storage is deleted                              | Isolated storage integration                             |
| REQB-25 | PublicReference known or guessed                                          | No lookup path; reference does not reveal existence, data, status or attachment                                                                         | OpenAPI + enumeration test                               |
| REQB-26 | READY_FOR_QUOTE tries direct transition to QUOTE_SENT                     | Rejected unless later quote module sends its approved immutable quote; no order is created                                                              | HTTP + contract negative                                 |
| REQB-27 | Concurrent upload-intent reservations approach the Inquiry quota          | Inquiry row lock and in-transaction recheck prevent concurrent reservations from exceeding file-count or total-byte limits                              | Real PostgreSQL concurrency + final-row evidence         |
| REQB-28 | Staff retries a saved mutation after losing Inquiry assignment/read scope | Current session, permission and Inquiry scope are checked before receipt lookup; no saved identifiers or response are disclosed                         | PostgreSQL + authorization regression                    |
| REQB-29 | Transition attempts to submit internalNote without comment permission     | Transition DTO has no free-text note; contextual notes use the separate comment command and permission/audit path                                       | OpenAPI negative + RBAC contract test                    |
| REQB-30 | Capability sent for create and later attachment commands                  | Create accepts the capability only in JSON; intent/upload/cancel use the dedicated header; no receipt, log or URL echoes it                             | OpenAPI/header contract test                             |
| REQB-31 | Staff attempts to clear an assignment                                     | Assignment DTO requires a non-null ACTIVE target; clearing is rejected and current assignment remains                                                   | OpenAPI negative + PostgreSQL regression                 |
| REQB-32 | Generic staff command closes before a quote or bypasses quote lifecycle   | No generic transition sets QUOTE_SENT/CLOSED; only later quote-lifecycle integration may close a QUOTE_SENT Inquiry                                     | OpenAPI negative + lifecycle contract test               |
| REQB-33 | Current-stage deadline set, cleared or stage changes                      | Staff queue/detail exposes stageDueAt; explicit change is audited/OCC-protected; status transition clears it; no automatic SLA/notification is inferred | PostgreSQL + audit + API contract                        |
| REQB-34 | Concurrent upload intents from one source span multiple Inquiries         | Atomic Redis source/UTC-day counter charges each declared size once and cannot exceed 25 MiB across Inquiry IDs                                         | Redis concurrency + multiple PostgreSQL Inquiries        |
| REQB-35 | Intent start expiry passes during a live upload                           | A stream started before expiresAt remains reserved and may finish only within its 15-minute receiving deadline; late stream aborts without attachment   | PostgreSQL clock + bounded stream fixture                |

All contract-only checks in this stage run without migrations, API code, uploads or production services. Runtime checks listed above are acceptance work for R1-010B after owner approval.
