## Обязательные runtime harness properties

- PostgreSQL — реальный test service/isolated database; race tests используют две независимые сессии и явные test barriers. До release первой транзакции harness подтверждает, что вторая действительно ждёт ожидаемую блокировку (например, по `pg_stat_activity` и `pg_blocking_pids`); после release проверяются committed rows и отсутствие запрещённого состояния. Одного `Task.WhenAll`, задержек по времени или проверки только конечных строк недостаточно. Public category response проверяется отдельно цепочкой keyset cursors на нескольких страницах и подтверждением, что каждый ответ ограничен запрошенным `pageSize`.
- HTTP проверяется через собранный Nest application и cookie/Origin/CSRF/RBAC границы, не через вызов service методов напрямую.
- Фикстуры синтетические и локальные; не добавлять seed товаров, брендов, файлов, поставщиков, цены или парольные credentials в приложение.
- Удаление/пересоздание разрешено только disposable test database. В CI/service data и локальные project volumes не удалять.
