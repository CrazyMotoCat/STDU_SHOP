# R1-006B — контрактная и runtime матрица приемки

**Статус: PROPOSED вместе с контрактом R1-006 0.1.0-proposed.** Выполнение начинается только после фиксации владельцем схемы/API/RBAC.

| ID     | Сценарий                                                                                                     | Обязательное доказательство                                                                                                                                                                                                                                                                  |
| ------ | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IMP-01 | Additive migration на пустой и populated PostgreSQL                                                          | Новые таблицы/FK/indexes/checks применяются; R1-002/R1-004 fixtures, protected permissions, audit и catalog rows сохранены; destructive down не удаляет данные                                                                                                                               |
| IMP-02 | Upload доступен только authenticated staff с `catalog.products.read` + `catalog.products.write` + CSRF       | Anonymous -> 401, read-only или write-only -> 403; upload не создаёт product/revision                                                                                                                                                                                                        |
| IMP-03 | Частный source FileObject/FileVersion                                                                        | SHA-256/size/MIME соответствуют байтам; storage key и FileVersion ID отсутствуют в ответах/логах; скачивания и public file route нет                                                                                                                                                         |
| IMP-04 | Поддельный MIME/extension, oversized file, invalid ZIP, zip bomb bounds, macro-enabled XLSM и внешние ссылки | Отказ до создания FileObject/FileVersion/run; чужие volumes/objects не читаются                                                                                                                                                                                                              |
| IMP-05 | XLSX с несколькими листами, header row, пустыми строками и различным порядком колонок                        | Raw rows доступны до mapping; выбранный header становится HEADER, omitted sheet — IGNORED; лист и исходный номер строки сохраняются, допустимые строки доступны независимо от ошибки другой строки                                                                                           |
| IMP-06 | CSV UTF-8/BOM, явно выбранный Windows-1251, неоднозначный delimiter, неизвестная кодировка                   | Поддерживаемые варианты читаются; неразрешённая кодировка/delimiter не угадывается и выдаёт явную ошибку                                                                                                                                                                                     |
| IMP-07 | Text SKU с ведущими нулями и XLSX zero-mask integer                                                          | Значение сохранено без округления/потери нулей, второе помечено warning; неподдержанный numeric/formula SKU не принимается                                                                                                                                                                   |
| IMP-08 | Formula, cached formula value, malformed row, oversized cell                                                 | Формула не вычисляется/не используется; только строка получает validation issue; остальные preview rows сохраняются                                                                                                                                                                          |
| IMP-09 | Explicit column/reference/attribute mapping                                                                  | Fixed Category/Brand IDs valid only for existing ACTIVE refs; category is required per accepted row; AttributeDefinition applies only to exact categoryId; no automatic creation or code-based inheritance                                                                                   |
| IMP-10 | Exact identity and file-internal duplicates                                                                  | Только FROZEN tuple даёт EXACT_MATCH; title similarity не объединяет; missing key -> NO_DEDUP_KEY; duplicate-in-file явно видим                                                                                                                                                              |
| IMP-11 | Per-row ACCEPT_CREATE                                                                                        | Root + DRAFT revision создаются атомарно через catalog domain command; остальные rows неизменны; submit/pending/published pointer отсутствует                                                                                                                                                |
| IMP-12 | Per-row ACCEPT_REVISION                                                                                      | Используются существующий target и catalog OCC; новая revision DRAFT; submit/review/publish не вызываются                                                                                                                                                                                    |
| IMP-13 | REJECT/HOLD и отсутствие массового принятия                                                                  | Одна команда меняет максимум одну строку; batch endpoint отсутствует; public product response неизменен                                                                                                                                                                                      |
| IMP-14 | Concurrent catalog update/archive/submit after preview                                                       | Два PostgreSQL connections, блокирующее ожидание и final state подтверждают один допустимый исход; conflict rollback не оставляет product overwrite или success audit                                                                                                                        |
| IMP-15 | Failure inserting success/conflict AuditEvent or Decision                                                    | Success transaction откатывает import, product root/revision/pointers и decision; conflict transaction откатывает row CONFLICT и conflict Decision; ни один исход не выглядит успешным без AuditEvent                                                                                        |
| IMP-16 | Upload and row-decision retries                                                                              | Same idempotency key/body returns one saved result; changed bytes/CSV options with same upload key conflict; conflict retry returns stored 409 without duplicate Decision/AuditEvent/product                                                                                                 |
| IMP-17 | Partial parser response and preview resume                                                                   | Valid source rows and bounded sourceParseIssues persist as SOURCE_PARTIAL; preview retry uses saved raw rows, does not call parser again, duplicate rows, or rewrite decisions                                                                                                               |
| IMP-18 | Public and role boundary                                                                                     | Нет import API/DTO/source data на public routes; новых permission codes нет; read/write/reference permissions совпадают с FROZEN R1-004; generic catalog read не раскрывает чужие imports                                                                                                    |
| IMP-19 | Exact FROZEN catalog regression                                                                              | Существующие CATB-01…38 и public catalog checks проходят без изменений                                                                                                                                                                                                                       |
| IMP-20 | E2E-03                                                                                                       | Staff загружает CSV/XLSX, задаёт mapping, видит raw/normalized preview, решает строки отдельно; guest не видит unapproved changes                                                                                                                                                            |
| IMP-21 | Raw source preview, owner visibility and mapping lifecycle                                                   | Uploader sees own raw cells before mapping; read-only cross-owner scope uses ACTIVE control admin + catalog read, cross-owner changes add write/reference permissions; audit, fixed per-sheet IDs and mapping edit lock are proven                                                           |
| IMP-22 | Private FastAPI parser boundary                                                                              | Private parser emits only valid versioned NDJSON; ordering, LF framing, record/batch bounds, terminal COMPLETE/PARTIAL, timeout and broken stream behavior are enforced before storage/persistence                                                                                           |
| IMP-23 | CSV options on initial upload                                                                                | UTF-8/BOM default, explicit Windows-1251, unique delimiter detection, explicit ambiguous delimiter, rejection of CSV options on XLSX; options/file bytes are in upload hash and immutable after upload                                                                                       |
| IMP-24 | CSV options cannot be changed in mapping                                                                     | JSON Schema has no `csvOptions` on or under `ImportMappingRequest.sheetMappings`; upload schema alone exposes CSV options; generated TS mapping type has no `csvOptions`; targeted contract regression passes                                                                                |
| IMP-25 | Per-sheet fixed Category/Brand                                                                               | Fixed values remove need for matching columns; fixed plus same-target column/reference mapping is rejected; fixed category requires matching category-specific attribute mappings; inactive/unknown IDs fail; sheets can differ; category-specific AttributeDefinition mapping remains exact |
| IMP-26 | Own/other import and decision access                                                                         | `catalog.products.read` sees own rows only; cross-owner read requires effective control-admin + catalog read, mutations additionally require catalog write/reference read; access and row-decision audits identify owner/scope                                                               |
| IMP-27 | ACCEPT_CREATE/ACCEPT_REVISION business conflict                                                              | HTTP 409 follows rollback of catalog attempt; row `candidateState=CONFLICT`, one decision `outcome=CONFLICT` with persisted `conflictCode`, and one DENIED AuditEvent commit atomically; same-key retry returns the same 409 code and adds no decision/audit; audit failure -> 503           |
| IMP-28 | NDJSON terminal and truncation                                                                               | Exactly one terminal COMPLETE/PARTIAL; malformed, truncated, oversized, duplicate-terminal or post-terminal streams are discarded with no FileObject/FileVersion/ImportRun/ImportRows                                                                                                        |
| IMP-29 | Parser timeout practicality                                                                                  | Representative and near-bound fixtures complete within the proposed 15 s; otherwise implementation pauses for owner contract decision; no silent limit increase                                                                                                                              |
| IMP-30 | Retention readiness for production                                                                           | R1 data is not automatically deleted; production use remains blocked until owner-approved retention/deletion/legal-hold/access/audit policy exists                                                                                                                                           |

Required final evidence: disposable PostgreSQL runtime tests, API/HTTP auth/RBAC tests, representative CSV and multi-sheet XLSX fixtures, injected parser/audit failures, two-connection OCC test, UI/E2E-03, independent backend/database/security reviews, and exact-candidate GitHub CI. No production DB or deployment is in scope.
